# Python-for-Data-Visualisatio

This project focuses on cleaning, analyzing, and visualizing taxi trip data using Python, Pandas, Matplotlib, and Seaborn.  
Performed data cleaning, handled missing values, and conducted exploratory data analysis (EDA).  
Created visualizations including line charts, bar charts, pie charts, histograms, box plots, scatter plots, heatmaps, pair plots, count plots, and violin plots.  
Analyzed taxi trip patterns, fare distributions, payment methods, and relationships between numerical variables.  
**Key Skills:** Python, Pandas, NumPy, Matplotlib, Seaborn, Data Cleaning, EDA, and Data Visualization.
