# Python-for-Data-Visualisation
# Taxi Dataset Analysis Using Python

##  Project Overview
This project focuses on cleaning, analyzing, and visualizing a Taxi Dataset using Python.  
The main objective is to understand taxi trip patterns, fare distributions, payment methods, and relationships between numerical variables.

##  Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Description
The project uses the built-in Taxis Dataset available in Seaborn.  
It contains information about taxi trips, including pickup and drop-off times, distance, fare, tips, tolls, payment methods, and pickup and drop-off locations.

##  Data Cleaning and Preprocessing
- Checked dataset dimensions, column names, and data types.
- Identified and analyzed missing values.
- Handled missing numerical values using median imputation.
- Handled missing categorical values using mode imputation.
- Removed rows containing missing pickup and drop-off timestamps.
- Compared the original and cleaned datasets.

##  Data Visualization

### Matplotlib and Pandas
1. **Line Chart:** Visualized average taxi fares over time.
2. **Bar Chart:** Compared total fares across pickup boroughs.
3. **Pie Chart:** Displayed trip distribution by payment method.
4. **Histogram:** Analyzed the distribution of taxi trip distances.
5. **Box Plot:** Compared tip distributions across pickup boroughs.

### Seaborn
1. **Count Plot:** Analyzed the number of trips by pickup borough.
2. **Scatter Plot:** Explored the relationship between distance and fare using borough colors.
3. **Heatmap:** Visualized correlations between numerical variables.
4. **Pair Plot:** Explored relationships between distance, fare, tip, and total across pickup zones.
5. **Violin Plot:** Compared fare distributions across payment methods.

### Key Learning Outcomes
- Gained practical experience in data cleaning and preprocessing.
- Learned to handle missing values using different imputation techniques.
- Improved understanding of exploratory data analysis (EDA).
- Practiced creating different visualizations using Matplotlib and Seaborn.
- Developed skills in identifying patterns and relationships within datasets.

## Conclusion
This project provided hands-on experience in Python-based data analysis and visualization.  
It helped develop a better understanding of taxi trip characteristics through exploratory data analysis.
